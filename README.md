## Estrutura
- `dataset/` – dados de origem compartilhados (`Financial Sample.xlsx`).
- `desafio-N-*/` – cada entrega, com o projeto Power BI e README próprio (D4 e D5 incluem prints).

> Os projetos usam o parâmetro `CaminhoDados` no Power Query para localizar o Excel; ajuste-o para a pasta `dataset/` da sua máquina ao abrir.
